# Projeto Machine Learning
## Objetivo
Ajudar uma equipe de RH a determinar quais funcionários vão pedir demissão, ou seja, a empresa deseja se antecipar caso haja a saida de um funcionário. Para propor antes algum incentivo para o mesmo permanecer na empresa.

## Bibliotecas
- **Pandas:** Leitura e manipulação de dados.
- **Scikit-Learn:** Algoritmos de Machine Learning utilizados.
- **Matplotib:** Visualização dos dados.
